# Banky Application

Use a concrete learning project to discuss account-management journeys and the safeguards they would require.

> **Current status:** Incomplete Java Servlet/JDBC educational prototype; not a safe or verified banking product.

## Who this is for

Software learners, technical reviewers, and requirements workshop participants.

## What is available—and what is not

Source and forms cover account/admin registration and account-related operations, but end-to-end behavior is unverified. Transfers are not implemented, authentication is not enforced as a safe session boundary, and credentials/configuration require remediation. Never use real money, customer records, PINs, or passwords.

## Example discovery workflow

*Fictional planning exercise, not a tested product workflow.*

1. Choose a fictional account journey using invented names and balances.
2. Review which forms and source paths exist and which steps are incomplete.
3. Turn security and correctness gaps into a prioritized learning backlog.

## Before any operational pilot

- Remediate embedded credentials and missing authentication/authorization enforcement.
- Reconstruct and validate database setup in an isolated environment.
- Test correctness and incomplete operations before any demonstration; no production banking use.

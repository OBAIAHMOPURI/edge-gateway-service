# Smart Shopfloor Monitor

Explore clearer production visibility and more useful shift handovers before investing in a shopfloor system.

> **Current status:** Campaign design brief; no implementation or live plant connection verified.

## Who this is for

Production supervisors, shift leads, and manufacturing process owners.

## What is available—and what is not

The campaign brief proposes a shared view of fictional production targets, interruptions, and handover notes. It does not collect PLC data, calculate live OEE, or control production equipment.

## Example discovery workflow

*Fictional planning exercise, not a tested product workflow.*

1. Describe a fictional production line and the information one shift needs to hand over.
2. Agree how operators would record a delay, assign an owner, and explain the next action.
3. Review a proposed shift summary with the team before specifying a pilot.

## Before any operational pilot

- Confirm production-data ownership and the meaning of each proposed metric.
- Use synthetic examples; any OT/PLC integration requires a separate security and safety review.
- Agree acceptance criteria and an implementation scope before promising a live dashboard.
